1. **smixs/osint-skill**
На Hermes був доданий новий скіл - **smixs/osint-skill**

| Питання | Ваша відповідь |
|---------|----------------|
| Як агент «бачить» skill? (де файл, як передається) | Якщо  ми хочемо додати новий скіл ми можемо його поставити зі Skills Hub aбо скопіювати наш скіл в папку "AppData\Local\hermes\skills\" (Windows).  При цьоиу ми мижемо набрати - /osint - в консолі і побачити чи скіл підтянувся Hermes (при цьому ми побачимо текст з поля *description* (малюнок зверху))|
| Яку роль відіграє файл SKILL.md? | Це спеціальний файл який розширює функціонал AI агента, додає певні знання, описує певні процечи, які можуть бути застосовані. Основними елементами файла є: name - назва документа; description - опис  скіла, для чого він призначений, яким тригером запускається; тіло скіла - де описані кроки до виконання,  формати вхідних і вихідних даних,  крайні випадки |
| Які додаткові файли, скрипти або reference-матеріали використовуються? | Такими файлами\папками є: `scripts` - містить спецеіфічні скрипти, які агенти  може запускати ![scripts](.images\scripts.png) Кожен sh файл представляє обгоркту над певниим api для пошуку данних.  `references` - містить певну документацію, яку може читати агент в певні моменти (містять додаткові інструкції під спецефічну тему) ![scripts](.images\ref.png) (наприклад: content-extraction.md - описує які дані вибирати при скрапінгу Youtube, блогів, подкастів etc. platforms.md - описє які дані брати для кожної конкретної платформи. tools.md - описує інструменти).  `assets` - містять шаблони документів, дані, формати даних  (![scripts](.images\assets.png)|
| Як організована логіка роботи skill'а (фази, кроки)? | Розрізнять наступні фази виконання: `Виявлення:` під час запуску агенти завантажують лише назву та опис кожної доступної навички — рівно стільки, щоб визначити, коли вона може знадобитися. `Активація:` коли завдання відповідає опису навички, агент зчитує повні інструкції з файлу SKILL.md і додає їх до контексту. `Виконання:` агент діє згідно з інструкціями, за потреби виконуючи доданий код або завантажуючи файли, на які є посилання.  |
| Які залежності, API або інструменти потрібні для повноцінної роботи? | Для повноцінної роботи AI агента нам потрібно забеспечити наявність відповідних інструментів виконання коду, LLM моделі, api ключі для доступу, інструменти, які агент може викликати - веб пошук, виконання коду, доступ до БД, термінал та інше |
 
У випадку даного скіла першим виконується файл - `diagnose.sh` - який перевіряє/діагностує, чи всі API ключі і токени проставлені і видає неведикий результат по даній перевірці -  Capability summary.
